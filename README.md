# Joined! NeoParty
Joined! NeoParty es un videojuego del género Party Game desarrollado por Joined! Entertainment.

Este videojuego está diseñado para ser jugado con los JoiPads, unos controladores creados para el juego. 
Todo este proyecto forma parte de mi Trabajo de Fin de Grado desarrollado para mi grado en Diseño y Desarrollo de Videojuegos.

En esta página podréis encontrar tanto el juego como los archivos 3D de los mandos (Releases).

Enlace al trailer: https://youtu.be/VUa7hCppVwM
